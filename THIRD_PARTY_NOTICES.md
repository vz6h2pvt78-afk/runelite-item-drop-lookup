# Third-party data

Monster locations and access text derive from **Old School RuneScape Wiki
contributors**, operated by Weird Gloop: https://oldschool.runescape.wiki/ .
The wiki reports **Creative Commons Attribution-NonCommercial-ShareAlike 3.0
Unported**: https://creativecommons.org/licenses/by-nc-sa/3.0/ . Copyright policy:
https://oldschool.runescape.wiki/w/RuneScape:Copyrights .

The location dataset is an adapted extraction: LocLine parsing, markup
normalization, access-note extraction, conservative drop associations and
separately curated classifications. It is a snapshot with coverage gaps. Every
row retains source page and revision ID; `docs/data/monster_locations_report.json`
contains the revision manifest. Contributor histories are accessible from the
linked wiki pages. A corresponding notice is bundled with the runtime resource.

Existing drop/shop/item/price resources retain their documented provenance and
release obligations. The proposed code license does not replace those notices.
