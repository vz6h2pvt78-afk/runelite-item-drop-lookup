## Remaining publication decisions and limits

1. Approve original-code copyright attribution and public-facing author. Before
   publication, install the approved BSD text as root LICENSE and as a bundled
   code-license notice, then update this document and the README's proposal wording.
2. Wiki adaptations retain CC BY-NC-SA 3.0 terms and exceptions. A BSD license for
   code does not change those terms. Reviewers can inspect the source URLs and
   adaptation descriptions; original revision IDs are unavailable for the older
   drop and shop snapshots, and must not be invented.
3. The real-time price API policy encourages community-facing tools, but the
   inspected policy does not state a separate explicit redistribution license
   for API numerical responses. Attribution and public API access are evidence
   of provenance, not a legal determination. Resolve any required permission or
   licensing clarification before claiming the entire distribution is cleared.
4. Explicit owner approval is required for a public source push and Plugin Hub
   PR. Approval/merge by RuneLite maintainers is separate from local test success.
